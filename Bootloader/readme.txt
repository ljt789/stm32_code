 ***************************************************************************************************
 * 实验名称 : FOTA 固件远程升级(第一阶段: 片内 Flash 读写)
 * 实验平台 : 正点原子 探索者 F407 开发板 (STM32F407ZGTx, Cortex-M4, 1MB Flash)
 * 开发环境 : Keil MDK 5.36 / ARM Compiler 5.06
 *
 * 实验目的 :
 *   1. 掌握 STM32F407 片内 Flash 的读取、编程与扇区擦除
 *   2. 理解 Flash "位只能 1 变 0、擦除以扇区为单位"的物理约束,
 *      以及这个约束如何决定数据区的布局方式
 *   3. 掌握 IAP(In-Application Programming, 在应用中编程)的基本原理,
 *      为后续实现 OTA 远程升级打下基础
 *
 * 实验现象 :
 *   1. 上电后串口打印 AT24C02 检测结果
 *   2. 向扇区 11 起始地址 0x080E0000 写入 4 字节, 回读并打印:
 *          read: 11 22 33 44
 *   3. LED0(红灯) 与 LED1(绿灯) 以 500ms 间隔交替闪烁
 *   4. 串口波特率 115200-8-N-1
 *
 ***************************************************************************************************
 * 一、工程目录结构
 *
 *   Drivers/
 *     BSP/
 *       AT24C02/                I2C 接口 EEPROM 驱动(硬件 I2C1)
 *       FLASH/                  STM32F4 片内 Flash 读写驱动  ★ 本阶段核心
 *       LED/                    LED 驱动
 *     CMSIS/                    Cortex-M4 内核支持 + STM32F4 器件定义
 *     STM32F4xx_HAL_Driver/     ST 官方 HAL 库
 *     SYSTEM/
 *       delay/                  延时(基于 SysTick)
 *       sys/                    系统时钟配置(168MHz)
 *       usart/                  串口驱动, 支持 printf 重定向
 *   Middlewares/                中间件(当前为空)
 *   User/
 *     main.c                    主程序
 *     stm32f4xx_it.c            中断服务函数
 *     stm32f4xx_hal_conf.h      HAL 模块裁剪配置
 *   Projects/
 *     MDK-ARM/                  Keil MDK 工程(atk_f407.uvprojx)
 *   Output/                     编译产物(.axf / .hex / .bin / .map)
 *   keilkill.bat                清理 Keil 中间文件的批处理
 *   readme.txt                  本文件
 *
 ***************************************************************************************************
 * 二、硬件资源
 *
 *   1. LED
 *        DS0(RED)   : LED0 - PF9
 *        DS1(GREEN) : LED1 - PF10
 *        低电平点亮
 *
 *   2. AT24C02 (EEPROM, 256 字节, 硬件 I2C1)
 *        SCL : PB8 (AF4)
 *        SDA : PB9 (AF4)
 *        从机地址 : 写 0xA0 / 读 0xA1
 *
 *   3. USART1 (用于 printf 打印与后续接收升级固件)
 *        TX : PA9  (AF7)
 *        RX : PA10 (AF7)
 *        波特率 : 115200
 *
 *   4. 系统时钟 : 168MHz (HSE 8MHz, PLL)
 *
 ***************************************************************************************************
 * 三、Flash 数据区规划
 *
 *   STM32F407ZG 片内 Flash 共 1MB, 划分为 12 个扇区, 大小不统一:
 *       扇区 0~3   : 各 16KB   0x08000000 ~ 0x0800FFFF
 *       扇区 4     : 64KB      0x08010000 ~ 0x0801FFFF
 *       扇区 5~11  : 各 128KB  0x08020000 ~ 0x080FFFFF
 *
 *   本工程当前布局:
 *       0x08000000 ~ 0x080DFFFF   应用程序代码区(实际占用不到 10KB)
 *       0x080E0000 ~ 0x080FFFFF   数据区(扇区 11, 128KB, 独占)
 *
 *   数据区选在最后一个扇区的原因:
 *       1. 离代码区最远, 程序增长时最不容易与之相撞
 *       2. 独占一个扇区, 擦除时不会波及别的数据
 *
 ***************************************************************************************************
 * 四、使用方法
 *
 *   1. 编译
 *        用 Keil MDK 打开 Projects/MDK-ARM/atk_f407.uvprojx, 直接 Build。
 *        编译后 Output 目录下生成 atk_f407.axf / .hex / .bin / .map。
 *
 *   2. 生成 bin 文件
 *        工程已配置 After Build 自动调用 fromelf 生成 bin:
 *          C:\Keil_v5\ARM\ARMCC\bin\fromelf.exe --bin -o "输出路径.bin" "输入路径.axf"
 *        该命令的路径是绝对路径, 移动工程目录或修改输出文件名后必须同步修改。
 *
 *   3. 下载与现象观察
 *        用 ST-Link 下载后复位, 打开串口助手(115200-8-N-1)观察打印信息。
 *
 ***************************************************************************************************
 * 五、注意事项
 *
 *   1. 擦除的最小单位是"整个扇区", 没有按字节擦除的操作。
 *      往某个地址写数据前, 必须保证该地址所在扇区已擦除(内容为 0xFF)。
 *
 *   2. Flash 写入不可逆: 只能把 1 变成 0, 不能把 0 变回 1。
 *      这就决定了流程永远是"先擦除, 再写入"。
 *
 *   3. 擦除具有破坏性且不可撤销。擦掉的扇区里所有数据都会丢失,
 *      而不仅仅是你要修改的那几个字节。
 *
 *   4. 严禁把数据写到程序代码区。地址落在 0x08000000 附近会擦掉程序本身,
 *      开发板当场失去响应, 需要重新烧录才能恢复。
 *
 *   5. 擦写寿命有限, 典型值约 1 万次。频繁更新的小数据建议放在
 *      AT24C02(EEPROM, 可字节改写, 寿命 100 万次)中。
 *
 *   6. 擦除与编程期间 CPU 从 Flash 取指会被阻塞, 擦一个大扇区需要
 *      数百毫秒, 期间中断响应会被明显延迟, 注意看门狗喂狗间隔。
 *
 *   7. 工程内所有源文件统一使用 UTF-8 编码, Keil 中请在
 *      Edit -> Configuration -> Encoding 里选择 UTF-8, 避免中文注释乱码。
 *
